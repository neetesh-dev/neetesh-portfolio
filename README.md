# Neetesh — Freelance Frontend Developer

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and content
- `style.css` — layout, colors, responsive styling and animations
- `script.js` — mobile navigation, current year and scroll reveal effects

## Before publishing

1. Open `script.js`.
2. Replace `your-email@example.com` with the email address you want clients to contact.
3. Review the About and Skills sections. Keep every skill accurate to your current experience.
4. The restaurant and coaching institute designs are practice/demo concepts, not paid client projects.

## Run locally

Open `index.html` in a browser. Google Fonts require an internet connection; fallback fonts are included.

## Publish with GitHub Pages

1. Upload all four project files to the root of a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Customization

Edit the text in `index.html` and the colors near the top of `style.css` (`:root`) to personalize the site.
